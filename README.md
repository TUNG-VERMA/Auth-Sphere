# AuthSphere Project

Full Authentication and Authorization Project using:

- Node.js
- Express.js
- MongoDB
- Mongoose
- Sessions
- Cookies
- JWT
- Validators
- Role-Based Access

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

## Features

- Signup
- Login
- Password Hashing
- Sessions & Cookies
- Logout
- Protected Routes
- Admin Authorization
- JWT Authentication
- Input Validation
